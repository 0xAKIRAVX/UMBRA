# نصب UMBRA روی آیفون — راهنمای کامل (فارسی)

این راهنما مخصوص کسانی است که **مک ندارند** و می‌خواهند اپ iOS یِ UMBRA را روی
آیفون خودشان نصب کنند. کل مسیر این است:

```
کد در گیت‌هاب → GitHub Actions (مکِ ابری) → فایل IPA → Sideloadly/AltStore → آیفون شما
```

---

## گام ۱ — گرفتن فایل IPA

CI ما روی سرورهای مکِ گیت‌هاب اپ را کامپایل می‌کند و خروجی را به‌صورت
Artifact آپلود می‌کند:

1. وارد `github.com/0xAKIRAVX/UMBRA` شوید (با اکانت خودتان).
2. تب **Actions** را باز کنید.
3. از ستون سمت چپ روی **iOS build (unsigned IPA)** کلیک کنید.
4. آخرین اجرای موفق (سبز) را باز کنید و به پایین صفحه اسکرول کنید.
5. از بخش **Artifacts** فایل `UMBRA-unsigned-ipa` را دانلود کنید — یک ZIP
   است که داخلش `UMBRA-unsigned.ipa` قرار دارد؛ آن را استخراج (Extract) کنید.

> اگر پس از آخرین push اجرایی نبود: دکمه‌ی **Run workflow** (سمت راست) را بزنید
> و `main` را انتخاب کنید؛ ۱۵ تا ۲۵ دقیقه صبر کنید.

IPA بدون امضاست (unsigned). آیفون فقط اپ‌های «امضاشده با اپل‌آی‌دیِ خود شما» را
اجرا می‌کند، پس مرحله‌ی بعد آن را با **اپل‌آی‌دی خودتان** امضا می‌کنیم.

---

## گام ۲ — نصب با Sideloadly (رایگان، ویندوز یا مک)

Sideloadly رایج‌ترین ابزار امضای شخصی است:

1. از `sideloadly.io` آخرین نسخه را نصب کنید.
   - **ویندوز:** حتماً iTunes هم باید نصب باشد (درایور USB آیفون).
   - **مک:** نیازی به iTunes نیست.
2. آیفون را با **کابل اصلی** به کامپیوتر وصل کنید و روی گوشی اگر پرسید
   «Trust This Computer?» را تأیید کنید. (VPN/فیلترشکن کامپیوتر را موقتاً خاموش کنید.)
3. Sideloadly را باز کنید؛ آیفون شما باید در فیلد Apple Account دیده شود.
4. فایل `UMBRA-unsigned.ipa` را داخل پنجره‌ی Sideloadly بکشید (Drag & Drop).
5. **Apple ID** خودتان را وارد کنید (همان ایمیل و پسورد اپل). رمز درخواست شود
   یعنی تأیید دو مرحله‌ای — کد ۶ رقمی را بزنید.
   > اگر خطای `-22621` یا مشکلی با پسورد داد، از
   > `appleid.apple.com` یک **App-Specific Password** بسازید و همان را وارد کنید.
6. اگر پیام آمد «Change Bundle ID?» تأیید کنید — اجباری است برای اکانت رایگان.
7. دکمه‌ی **Start** را بزنید و صبر کنید تا روی گوشی نصب شود.

### بدون کامپیوتر؟ AltStore
اگر به کامپیوتر دسترسی ندارید، با **AltStore** هم می‌شود نصب کرد — AltServer را
روی کامپیوتری در همان شبکه (یا دستگاه دیگری) اجرا کنید، IPA را داخل AltStore
از طریق Share Sheet بفرستید و Install را بزنید.

---

## گام ۳ — فعال‌سازی روی آیفون (فقط بار اول)

اپل اپ‌های امضاشده با اپل‌آی‌دی شخصی را تا وقتی «اعتماد» نکنید باز نمی‌کند:

1. روی آیفون: **Settings → General → VPN & Device Management**
   (فارسی: تنظیمات ← عمومی ← VPN و مدیریت دستگاه).
2. روی ایمیل اپل‌آی‌دی خودتان (Developer App) بزنید → **Trust** → تأیید.
3. حالا آیکون UMBRA از صفحه‌ی اصلی باز می‌شود. 🎉

## محدودیت‌های اکانت رایگان (خلاصه و صادقانه)

| مورد | اکانت رایگان اپل | اکانت توسعه‌دهنده (۹۹$ در سال) |
| --- | --- | --- |
| اعتبار امضا | **۷ روز** — بعدش اپ باز نمی‌شود | یک سال کامل |
| تعداد اپ | ۳ اپ هم‌زمان | نامحدود |
| رفرش | باید دوباره به کامپیوتر وصل کنید و Start بزنید | لازم نیست |
| TestFlight | ❌ | ✅ (نصب راحت‌تر برای بقیه) |

- رفرش هفتگی با Sideloadly دوباره‌ی همان کار ۲ دقیقه‌ای است؛ داده‌ها پاک
  نمی‌شوند (resultها داخل خود اپ هستند؛ اگر نگرانید، قبل از رفرش خروجی CSV/JSON بگیرید).
- این محدودیت‌ها قانون اپل است، نه باگِ اپ — راه دور زدن ندارد.
- برای انتشار عمومی (TestFlight / App Store) به اکانت ۹۹ دلاری نیاز است و
  احتمال ریجکتِ ابزار اسکن IP در بازبینی اپل هم باید در نظر گرفته شود.

## مشکلات رایج

- **«Untrusted Developer»** → گام ۳ را انجام نداده‌اید.
- **نصب می‌شود ولی بعد از ۷ روز باز نمی‌شود** → دوباره Sideloadly وصل کنید و
  Start بزنید (همان کابل، همان اپل‌آی‌دی).
- **خطای provisioning (-1009, -4026…)** → از اکانت رایگان بیش از ۳ اپ نصب
  کرده‌اید؛ یکی را پاک کنید یا bundle ID را در Sideloadly عوض کنید.
- **کامپیوتر آیفون را نمی‌بیند** → کابل اصلی، Trust زده شود، iTunes نصب باشد،
  VPN کامپیوتر خاموش باشد.
- **اسکن داخل اپ جواب نمی‌دهد** → اول تب Settings را چک کنید: هویت (identity)
  باید ثبت/تازه باشد؛ اپ فقط با وای‌فای/دیتای فعال کار می‌کند و باید صفحه
  باز بماند (iOS اپ را در بک‌گراند می‌خواباند — مثل هر ابزار تست شبکه).

## خلاصه‌ی یک‌خطی

**Actions → iOS build → دانلود Artifact → استخراج IPA → Sideloadly + اپل‌آی‌دی
→ کابل USB → Install → Trust در تنظیمات → تمام.**
